Ethiopian Advanced Calculator
=============================

An advanced scientific calculator built with Kivy, supporting basic arithmetic, scientific functions, calculus, physics formulas, matrix operations, and graph plotting.

------------------------------------------------------------

FEATURES
------------------------------------------------------------

Basic Operations:
- Addition, subtraction, multiplication, division
- Brackets support
- Decimal numbers
- Backspace and clear functions

Scientific Functions:
- sin, cos, tan
- log, ln
- Square root (√)
- Constants: π and e

Advanced Mathematics:
- Derivatives (d/dx)
- Integrals
- Limits
- Determinant of matrices
- Matrix inverse

Physics Calculations:
- Force: F = ma
- Kinetic Energy: KE = 1/2 mv^2
- Potential Energy: PE = mgh

Graphing:
- Plot graphs (default: sin(x))
- Uses Matplotlib

Matrix Mode:
- Example input: [[1,2],[3,4]]
- Supports determinant and inverse

INSTALLATION
------------------------------------------------------------

1. Clone the repository:
   git clone https://github.com/your-username/ethiopian-calculator.git
   cd ethiopian-calculator

2. Create virtual environment (optional):
   python -m venv venv
   source venv/bin/activate        (Linux/Mac)
   venv\Scripts\activate           (Windows)

3. Install dependencies:
   pip install kivy numpy sympy matplotlib

------------------------------------------------------------

USAGE GUIDE
------------------------------------------------------------

Basic Input:
- Use numbers and operators like a normal calculator
- Press "=" to calculate

Scientific Functions:
- Enter a number, then press:
  sin, cos, tan, log, ln, √

Physics Mode:
- Force: enter "mass,acceleration" then press F=ma
- KE: enter "mass,velocity" then press KE
- PE: enter "m,g,h" then press PE

Matrix Operations:
- Enter matrix like: [[1,2],[3,4]]
- Press:
  det → determinant
  inv → inverse

Graphing:
- Press "Plot" to display a graph (default: sin(x))
